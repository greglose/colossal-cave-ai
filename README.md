# Colossal Cave AI

Work in progress: the original Colossal Cave Adventure (Will Crowther and Don Woods) in your browser, with AI-made
pictures and video from your own OpenRouter key. It uses Graham Nelson's Z-machine port, `Advent.z5`, which you load
yourself: the file has no stated redistribution license, so it is not included in this repository.

Sister project: https://github.com/greglose/zork-ai
